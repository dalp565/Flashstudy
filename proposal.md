## Free to use study program.

## Repository
Link to repository: <https://github.com/dalp565/Flashstudy.git>

## Well, what is this?
With the loss of free programs like Quizlet students are losing spaces they can store and practice
their written materials and notes.
This project aims to rebuild that space. More imprtantly this project allows the user to input
study methods that suit their needs. i.e. Flash cards/Self made quizzes

## Features:
 - Build Flashcards

 - Take user input and turn it into saved files that can be opened and read.

 - Create a "Quiz mode" from user input of study materials
 

## Challenges
- Building a code that creates a windowed application for study.
- Code should create flash cards with user input data.
- Program should store data locally within the program files and be able to reopen them.
- Build a couple of minigames for the code.

## Outcomes
Ideal Outcome:
- This code creates a program that stores and builds flash cards and study systems for the user.
- It will also hopefully use a window that is reizable like a browser.

Minimal Viable Outcome:
- Program runs and stores user input data for study.
